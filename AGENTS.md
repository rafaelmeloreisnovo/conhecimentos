# conhecimentos — public evidence ontology

Owns public contracts, falsifier fixtures and interpretation boundaries only.
Device-generated SELF_REPORT is not external attestation.
CI acceptance proves the envelope's structure and digest, not its truth, APK origin,
physical device, credentials, privacy completeness or GitHub server authorization.
Never upload PAT, personal credentials, repository contents, Android logs, screenshots,
phone identifiers, private folder identifiers, emails, local paths, or raw corpus here.
No publication/promotion of scientific or product claims from green schema checks.
Real device receipts stay private by default (e.g. trusted Drive recipient).
Source fixes occur in their producer repository, not this ontology repo.
